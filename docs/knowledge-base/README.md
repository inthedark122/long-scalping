# Trading pattern knowledge base

This folder records chart cases that can inform strategy rules. Each pattern
starts as a hypothesis. Keep observations separate from conclusions, and add a
case with its run, symbol, timeframe, MRC settings, and position outcomes before
changing strategy behavior based on it.
